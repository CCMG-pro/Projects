YOSEMITE VILLAGE PROJECT PAGE

Address: https://projects.ccmgpro.com/yosemite/
Hosting: GitHub Pages, from the CCMG project-site repository, folder /yosemite.
Publishing: Claude builds each update from the Project Hub and pushes it to GitHub after the PM approves the weekly preview. Nobody uploads files.

One-time firm setup (see module spec 4C): CCMG GitHub organization, access token for Claude, one CNAME record for projects.ccmgpro.com, then Claude sets up the repository, Pages and HTTPS.

Contents:
- index.html: the resident page. Static, no outside scripts, fonts or trackers.
- status.json: building statuses and dates. Rewritten by each publish.
- aerial.jpg, ccmg-logo.png, qr-yosemite.png: images.
- downloads/: resident PDFs exported from the canvas with fixed file names.

Before printing anything new: regenerate the QR to https://projects.ccmgpro.com/yosemite and ask the webmaster for a redirect from ccmgpro.com/yosemite if any notice with the old QR is already out.

Public content rules: zone-level progress and resident logistics only. No issue log, damage reports, resident names or unit numbers.
